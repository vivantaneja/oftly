# Oftly brand implementation

The user-supplied *Oftly Brand Identity.pdf* (10 November 2026) is the visual authority for this redesign. The implemented system follows its ink, index-paper, marigold and leaf palette, interval mark and type pairing.

- Ink `#1F2A44`: navigation rail, text and primary actions.
- Index paper `#F7F2E8`: study cards and supporting surfaces.
- Marigold `#F4B23E`: the final interval dot and the Good rating’s background, with ink text.
- Leaf `#2F7A5F`: success and visible focus.
- Bricolage Grotesque: outlined wordmark, headings and card questions.
- Atkinson Hyperlegible: body text, answers and controls.

The interval mark has four dots with growing radii and edge-to-edge gaps of 3, 6 and 12 units. Their bottoms align. The favicon uses two dots at small sizes. Both wordmark colours are outlined SVG; the mark is recreated as vector geometry from the supplied construction. Fonts are self-hosted, so normal study makes no font-service requests. Source URLs and OFL licences accompany the font files.

The reveal interaction keeps the question stationary. Its final dot changes to marigold as answer feedback appears; reduced-motion preferences disable the animation. This is a brand accent, not a representation of a card’s actual review history or a claim of mastery.

Native Anki model names, collection configuration keys and the existing local request header remain stable for compatibility. The GitHub repository URL remains unchanged. The PDF’s preliminary naming screen is not treated as verified legal clearance or repeated as a clearance claim.
